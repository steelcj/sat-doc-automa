# English Documentation

## Automa

Standing directives that produce consistent behavior mechanically, organized per-format:

- [AI collaboration](automa/ai-collaboration/) directives for AI collaboration sessions
- [Markdown](automa/markdown/) directives for markdown documents

Each format directory contains `defaults/` (in force) and `examples/` (alternatives).
